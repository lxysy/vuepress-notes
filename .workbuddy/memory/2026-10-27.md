### 踩到的两个坑（重要，以后别再犯）
- **enhanceApp 覆盖顺序相反**：`@vuepress/core` 中 internal-enhance-app 插件先注册，theme/用户插件后注册 → 用户的 enhanceApp 先执行，会被 `vuepress-plugin-smooth-scroll` 的 enhanceApp 顶掉。解法：先赋一次，再在 `router.onReady()` 里复核归属。
- **CSS `scroll-behavior: smooth`**：smooth-scroll 插件注入了 `html{scroll-behavior:smooth}`，逐帧 `window.scrollTo` 会被浏览器二次平滑，动画被拉长到 1s+。解法：`jumpTo()` 里临时把 `html.style.scrollBehavior='auto'`，滚动后再还原；动画期间 `realign` 直接 return。

## `npm run docs:dev` 报 `--openssl-legacy-provider is not allowed in NODE_OPTIONS`

### 根因（与最初判断不同，重要）
- 用户终端 PATH 里的 Node 是 **`F:\nodejs\node.exe` v16.20.0**（WorkBuddy 自带的是 22.22.2，容易看错）
- Node 16 用的是 OpenSSL 1.1.1，**根本不认识 `--openssl-legacy-provider`**（17 才引入），所以放 NODE_OPTIONS 报 "not allowed"，直接传则报 "bad option"
- 需要这个参数的是 **Node 17+**：对方是 `terser-webpack-plugin@1` 在 `dist/index.js:217` 里**硬编码** `crypto.createHash('md4')` 算缓存 key，**`output.hashFunction` 覆盖不了**，只能开 legacy provider
- 因此「保留参数」会在 Node 16 上炸，「删掉参数」会在 Node 18/22（CI 与新版 Node）上炸

### 解法
- 新增 `scripts/vuepress.js`：按 `process.versions.node` 主版本号决定是否加 `--openssl-legacy-provider`（≥17 才加），再用 `spawnSync` 调 `vuepress/cli.js`
- 注意：vuepress 的 `exports` 只暴露 `.` 和 `./config`，`require.resolve('vuepress/cli.js')` 会 `ERR_PACKAGE_PATH_NOT_EXPORTED`，必须用 `path.dirname(require.resolve('vuepress'))` 拼 cli.js
- package.json：`docs:dev` / `docs:build` 都改为 `node scripts/vuepress.js <cmd> docs`
- `.github/workflows/doc.yml`：删掉 step 级 `NODE_OPTIONS: --openssl-legacy-provider`（脚本自适应，CI 的 Node 18 会自己加）
- `cross-env` 现已无人使用（且 v10 要求 Node ≥20，与本地 Node 16 冲突），可择机移除

### 验证
- Node 16 `npm run docs:dev`：`Compiled successfully`，8080 返回 200
- Node 16 构建：Server + Client 均 `Compiled successfully`，crypto 报错 0
- Node 22 构建：同样只跑编译阶段即成功，无 digital envelope 报错
